# Test vectors

There are two implementations of BFF "Contracts":

1. the C# library `BigFatFile.Contracts`;
2. the TS package `@bigfatfile/client`.

JSON fixtures that both "Contracts" implementations run. Any change
here is a change to the contract between clients and servers.

- `chunking.json`: the chunks and hashes of a set of inputs.
    - Generated by `generator/` with the reference Rust crates, `fastcdc` and `blake3`.
    - Inputs are described, not stored: BLAKE3 extended output of a seed, or zeros.
    - To regenerate, from the repo root run:

        ```sh
        docker run --rm -v "$PWD/sdk/test-vectors":/work \
            -w /work/generator -u "$(id -u):$(id -g)" \
            -e CARGO_HOME=/tmp/cargo -e CARGO_TARGET_DIR=/tmp/target \
            rust:1-slim cargo run --release -- /work/chunking.json
        ```

- `names.json`: name keys (`Architecture.DataModel.md`, section 1).
    - The expected keys were computed from `CaseFolding.txt` and
      Python's `unicodedata`, independently of both implementations.
    - The folding table both implementations use comes from
      `node sdk/unicode/generate-case-folding.mjs`.
